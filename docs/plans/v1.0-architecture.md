## 1. What we are building

**LedgerLens MCP** — a production-grade [Model Context Protocol](https://modelcontextprotocol.io) server for **Kosha Financial**, a fictional Indian neobank. AI agents use it to:

- look up customers, accounts, KYC state and transactions (synthetic, regulator-realistic data);
- investigate AML alerts and screen entities against sanctions/PEP lists;
- raise disputes and flag transactions (idempotent, audited writes);
- search ~85 internal SOPs, policies and API docs across 9 departments (hybrid RAG with citations).

It exists to demonstrate production engineering: OAuth 2.1 auth, scope-level authorization, PII masking, resilience patterns, observability, IaC, CI/CD and a complete test pyramid.

| Network | VPC, private subnets for Lambda + RDS, **NAT instance** (t4g.nano), free S3/DynamoDB gateway endpoints |
| IaC | **AWS CDK (Python)** + `cdk-nag` |
| Deploy | GitHub Actions → OIDC → `cdk deploy`; **CodeDeploy canary** (10% for 5 min) on Lambda aliases with alarm-based automatic rollback |
| Observability (AWS) | Powertools for AWS Lambda (logs, metrics, idempotency) + OpenTelemetry → X-Ray; CloudWatch dashboard & alarms |
| Observability (local) | OpenTelemetry Collector → **Prometheus + Grafana + Tempo**, provisioned dashboards (compose profile `observability`) |
| Agent observability | Langfuse (LangGraph agent traces) |
| Clients | LangGraph "Kosha Ops Copilot" (primary), Google ADK example, Streamlit console UI, Claude Desktop config |
| Load testing | **Locust** (Python) — replaces k6 to keep one language |
| Docs | **MkDocs Material** on GitHub Pages; Mermaid + Excalidraw + animated SVG infographics |
| Region / account | Single AWS project, Region `eu-north-1`, FREE plan |
| Budget | ≈ $25/month while running; `poe pause` / `poe resume` stop RDS + NAT when not demoing |

### Tooling questions answered

| Tool | Verdict | Reason |
|---|---|---|
| **ngrok** | Dev-only, optional (`poe tunnel`) | Lets claude.ai reach a *local* server during development. Never part of production; the deployed CloudFront URL replaces it |
| **Prometheus + Grafana** | Yes — **locally** | Vendor-neutral OTel instrumentation feeds Grafana dashboards in compose (great screenshots). In AWS, Amazon Managed Grafana is not available on the plan and self-hosting costs money, so the same OTel data goes to CloudWatch/X-Ray |
| **Load balancer (ALB)** | No | ~$18/month for nothing API Gateway + CloudFront don't already provide for Lambda |
| **CodeDeploy** | Yes | Canary traffic shifting + automatic rollback on CloudWatch alarms — real production deployment safety at near-zero cost |
| **CodePipeline** | No | GitHub Actions is the pipeline; adding a second orchestrator adds nothing |
| **Kafka / MSK** | No | Paid-plan only, ~$100s/month, no streaming workload |

## 5. Resilience design

| Pattern | Where | Notes |
|---|---|---|
| Deadline propagation | every hop | Request budget set at gateway; each downstream call gets `min(remaining − margin, per-call cap)` |
| Timeouts | httpx, psycopg, OpenAI | Connect / read / pool timeouts set explicitly; never library defaults |
| Retry | idempotent calls only | Exponential backoff + full jitter, max attempts, **retry budget** (≤ 10% extra load) |
| Circuit breaker | per downstream, per instance | closed → open → half-open; failure-rate window; DynamoDB force-open override shared across instances |
| Bulkhead | per downstream | `asyncio.Semaphore` caps; Lambda reserved concurrency caps DB connections |
| Rate limiting | per OAuth client | DynamoDB token bucket (60 req/min, burst 20) → `429` + `Retry-After` |
| Idempotency | write tools | Key + request hash stored in the same Postgres transaction as the write |
| Load shedding | gateway | Reject early when in-flight > limit or remaining budget too small |
| Graceful degradation | KB search, screening | FTS-only search when OpenAI fails; `screen_entity` returns `status: deferred` when vendor breaker open |
| Fault injection | gateway + sim | Signed chaos header / config: latency, errors, timeouts per dependency |

## 8. Test strategy

| Layer | Scope | Tooling |
|---|---|---|
| Unit | domain rules, validators, masking, state machines, resilience primitives | pytest, hypothesis (property-based) |
| Integration | repositories, migrations, SQL retrieval, outbox, SQS consumers | testcontainers (Postgres+pgvector), LocalStack |
| Tool | every MCP tool via FastMCP in-memory client with real core-api | pytest-asyncio |
| Contract | tool/resource/prompt schemas snapshot; OpenAPI snapshot | syrupy |
| E2E | deployed stack, real Cognito tokens, every tool | pytest + MCP client |
| Load / chaos | SLO verification; breaker open → half-open → close | Locust, chaos header |
| RAG eval | recall@k, MRR, faithfulness on golden set | pytest + DeepEval |

**Per-tool failure matrix** (each row tested for each tool where applicable): missing / expired / wrong-audience token · missing scope · masking per role · invalid input · not found · empty result · oversized result truncation · tampered cursor · downstream timeout · downstream 5xx · breaker open · rate limited · idempotent replay · idempotency conflict · concurrent duplicate · OpenAI outage → degraded · DB pool exhausted · prompt-injection content in KB results.

Coverage gate: 90% lines on `packages/` and `services/`.
